## Repository Name
fullstack_developer_capstone

## Project Name
fullstack_developer_capstone

## Project Description
This project is a full-stack web application developed using Django and React. It provides functionality for displaying car dealerships, retrieving dealer information, viewing and submitting dealer reviews, and managing user authentication.

## Technologies Used
- Python
- Django
- React.js
- JavaScript
- HTML
- CSS
- REST APIs
- Git and GitHub

## Project Objectives
- Display available car dealerships.
- Retrieve dealer information and reviews.
- Filter dealerships by state.
- Allow users to register, log in and log out.
- Enable users to submit dealership reviews.
- Perform sentiment analysis on customer reviews.
- Deploy the application using CI/CD.
